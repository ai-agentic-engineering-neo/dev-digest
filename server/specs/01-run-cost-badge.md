# 01 — Run Cost Badge

**Goal:** every finished agent run shows its USD cost (and tokens), and every PR shows what its current review cost. No extra model calls: cost is already computed per run in `reviewer-core` (`reviewPullRequest` → `costUsd`; OpenRouter's real `usage.cost`, else `PriceBook` / `adapters/llm/pricing.ts`). It used to be dropped in `run-executor.ts`; this feature **saves it, exposes it, renders it**.

## Where it shows up
1. **PR list** — new `COST` column between STATUS and UPDATED, compact (`$0.014`). Value = sum of the **latest `done` run per agent** for that PR.
2. **PR timeline (Agent runs)** — under the run's timestamp: `9,119 tok · $0.0013` (tok = tokens_in + tokens_out). Only for `done` runs.
3. **Run trace drawer → Stats** — new `COST` tile between TOKENS and FINDINGS.
4. **Verdict banner (PR Detail review accordion)** — `$0.014 · 8k→1.3k` for the run that produced the review.

## Rules / acceptance criteria
- No data (null cost, runs from before the migration, failed/cancelled runs, never-reviewed PR) → `—`, **never `$0.00`**. A real `0` (free model) → `$0`.
- One adaptive formatter (`formatCost`, `client/src/app/repos/[repoId]/pulls/helpers.ts`): `<$0.01` → 4 decimals, `<$1` → 3, else 2; a positive amount under `$0.0001` → `<$0.0001`.
- PR aggregate: newest `done` run per `agent_id`; null costs are skipped; none left → `null`. Re-runs replace, never add (`modules/pulls/cost.ts` · `aggregatePrCost`).
- No backfill: old runs stay `null`. No change to grounding / `INJECTION_GUARD`.

## Contract / data changes
- `agent_runs.cost_usd double precision NULL` (migration `0010_*`, generated by `db:generate`).
- `RunStats.cost_usd` (nullish — old trace jsonb still parses), `RunSummary.cost_usd` (nullable), `PrMeta.cost_usd` (nullish, list endpoint only). Edited identically in `server/` and `client/` `vendor/shared`.
- `GET /pulls/:id/runs` and `GET /repos/:id/pulls` expose it; the verdict banner reuses the runs query the page already loads (no new endpoint).

## UI components
- NEW `pulls/_components/RunCostBadge` — variants `cost` | `timeline` | `inout`.
- MODIFIED `PRRow` + `constants.ts` (GRID, COLUMN_KEYS), `RunHistory`, `RunTraceDrawer/.../TraceBody`, `VerdictBanner`, `ReviewRunAccordion`, `FindingsTab`.
- i18n: `prReview.json` (`list.columns.cost`, `timeline.tokens`), `runs.json` (`trace.stat.cost`).

## Out of scope
Cost on failed runs (their tokens are stored as 0 too), budgets/alerts, Agent Performance and Eval dashboards, the list's FINDINGS column and per-row Run Review button shown in the mockup.
