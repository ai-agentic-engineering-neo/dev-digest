# Rules

Always-applied project rules and guardrails — as opposed to `.claude/skills/`,
which loads on-demand when an agent judges a skill relevant.

Empty for now. Add a rule file here when a project-wide constraint needs to
be enforced on every session (not just referenced from a `CLAUDE.md`). Once a
rule file exists here, it is authoritative over every `CLAUDE.md` in this
repo — `CLAUDE.md` files must defer to it, never override it.
