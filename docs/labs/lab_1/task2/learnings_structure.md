# LEARNINGS.md File Structure

The file structure is fixed (as verified by MindStudio) and must not be free-form text. Every `LEARNINGS.md` must contain the following sections:

## Required Sections

| Section | Description |
| :--- | :--- |
| **What Works** | Document approaches and solutions that were successful. |
| **What Doesn't Work** | Identify blind spots and anti-patterns. (Note: This is the most valuable section but often skipped). |
| **Codebase Patterns** | Document conventions and architectural decisions. |
| **Tool & Library Notes** | Record specific quirks regarding dependencies. |
| **Recurring Errors & Fixes** | Log repeating errors alongside their respective fixes. |
| **Session Notes** | Dated summaries of individual development sessions. |
| **Open Questions** | List any items that remain unresolved. |

> **Note:** The AI agent is responsible for writing to the corresponding section based on the context of the task.
