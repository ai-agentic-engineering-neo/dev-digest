# server (@devdigest/api)

Fastify 5 API on port 3001. Stack: TypeScript ESM (`"type": "module"`), Node >= 22, Drizzle + Postgres/pgvector, Zod, Vitest + Testcontainers.

## Commands
- `pnpm install`
- `pnpm dev` (tsx watch, :3001), `pnpm build`, `pnpm start`
- `pnpm db:generate`, `pnpm db:migrate`, `pnpm db:seed`

## Verify
- `pnpm typecheck`
- `pnpm test` (`vitest run`): includes `*.it.test.ts`, needs Docker
- Hermetic only: `pnpm exec vitest run --exclude '**/*.it.test.ts'`; integration only: `pnpm exec vitest run .it.test`
- No linter or formatter is configured; do not add a lint command.

## Naming conventions
- Tests are `*.test.ts` in `test/`; `*.it.test.ts` are DB-backed, all others hermetic.
- Feature modules are kebab-case folders under `src/modules/` with `routes.ts`, `service.ts`, `repository.ts` (`reviews/repository/*.repo.ts`); `_shared` is the underscore folder.
- Mock doubles are `Mock*` classes in `src/adapters/mocks.ts`. Migrations are `NNNN_name.sql`.

## Hard rules and gotchas
- `*.it.test.ts` use testcontainers via `test/helpers/pg.ts`; everything else must be hermetic.
- Route schemas are Zod contracts from `@devdigest/shared`; do not redefine them locally.
- Feature modules are registered statically in `src/modules/index.ts`; adapters are injected via `src/platform/container.ts`.
- Migrations are not run on boot; run `pnpm db:migrate`.
- DO NOT TOUCH `src/db/migrations/` (`*.sql`, `meta/`): generated by drizzle-kit; never hand-edit, delete or edit an applied migration. Change `src/db/schema.ts`, then `pnpm db:generate` and `pnpm db:migrate`.
- `src/vendor/shared` is vendored (`@devdigest/shared`, also imported by reviewer-core); no sync script exists, do not edit it here.

## Folder map
- `src/`: `app.ts` builds the app, `server.ts` is the entrypoint
- `src/adapters/`: adapter implementations plus `Mock*` doubles
- `src/db/`: Drizzle setup, `schema.ts`, migrations, seed
- `src/modules/`: feature modules (Fastify plugins registered in `index.ts`)
- `src/platform/`: config, DI container, errors, job runner, SSE bus
- `src/prompts/`: editable prompt templates
- `test/`: Vitest suites and helpers
