# specs — cross-module

Feature specs that touch more than one module. Single-module features go in `<module>/specs/`.
Name files `M<n>-<slug>.md` (e.g. `M1-run-cost-badge.md`).

Template:

```markdown
# M<n> · <Feature>
Status: draft | in-progress | done
Modules: server, client

## Goal
## Non-goals
## Design
## Acceptance criteria
- [ ] ...
## Open questions
```
