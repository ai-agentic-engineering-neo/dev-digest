# e2e/specs/

Product/feature specs for this package (requirements — what a user flow
should cover — not test-flow definitions). Test flow JSON files
(`NN-name.flow.json`) live in [`../specs_old/`](../specs_old/); that path was
renamed to free `specs/` for this purpose, and `run.ts`'s `SPECS_DIR` already
points at `specs_old`. Link a new spec from [`../CLAUDE.md`](../CLAUDE.md)
under "Read when" once it exists.
