Map for `@devdigest/api`. Root map: [../CLAUDE.md](../CLAUDE.md). Deep dive: [README.md](README.md).

## Role

Fastify API: DB (Postgres/Drizzle), GitHub sync (Octokit), review orchestration,
the `repo-intel` codebase indexer. The DB schema already has every table the
whole course uses — most sit empty until a later lesson fills them.

## Run / test

```sh
pnpm dev                                                        # :3001
pnpm db:migrate && pnpm db:seed                                 # NOT automatic on boot
pnpm exec vitest run --exclude '**/*.it.test.ts'                # unit, no Docker
pnpm exec vitest run .it.test                                   # integration, needs Docker
pnpm typecheck
```

## Non-default conventions

- Module files are named by **role**: `routes.ts`, `service.ts`, `repository.ts`,
  `helpers.ts`, `constants.ts` in each `src/modules/<name>/`.
- Schema files (`src/db/schema/*.ts`): kebab-case, one per domain; `camelCase`
  columns map to `snake_case` in Postgres.
- Business logic stays DB/GitHub-agnostic where possible — real I/O sits behind
  adapters in `src/adapters/*` (swapped for mocks in tests via `adapters/mocks.ts`).

## Gotchas

- `src/vendor/shared` is a **manually duplicated copy** of the same contracts also
  vendored into `client/src/vendor/shared` — not a symlink, no sync script. Edit
  one, then copy the change to the other by hand.
- CLI-entrypoint checks (`migrate.ts`, `seed.ts`) must compare
  `fileURLToPath(import.meta.url) === process.argv[1]`, not a hand-built
  `file://` string — the latter silently never matches on Windows.
- `pgvector` extension must exist before vector-column tables; `migrate.ts`
  creates it, so always migrate through that script, not raw SQL.
- `package.json` is `skip-worktree` locally (per TESTING.md) — CI runs the
  test split via `pnpm exec vitest run …` directly, not a `test:unit` script.
- `clones/**` is runtime data (git-ignored) — never expect it in a fresh checkout.

## Do not touch

- `src/db/migrations/**` — generated by `drizzle-kit generate`; see root CLAUDE.md.
- `pnpm-lock.yaml`.
