# Task 2: Writing the First Skill — Engineering Insights

## Overview
The "Engineering Insights" skill is the primary skill of this course. It must be implemented immediately after `CLAUDE.md` to prevent error accumulation in subsequent laboratory tasks.

## Implementation Details
Do not provide a finished product. The goal is to implement a template consisting of:
- **Instruction:** 5–8 lines of guidance.
- **Header:** A YAML block containing:
  - `name`
  - `description-trigger`

## File Locations
Entries must be written to the specific `LEARNINGS.md` file belonging to the module being addressed. 

**Target Directories:**
* `apps/client`
* `apps/server`
* `packages/reviewer-core`
* `packages/repo-intel`

*Note: Each module must maintain its own independent file to ensure that agent context remains focused on relevant lessons and avoids "noise" from other modules.*
