# Insights

failed and why. Append-only — newest at the bottom. Read before changing
non-trivial code here; add an entry when you learn something the code doesn't say.

Entry format:

```
## YYYY-MM-DD — short title
**Context:** what you were doing
**Insight:** what was non-obvious / what went wrong
**Rule:** what to do (or avoid) next time
```
