# DevDigest

Local-first AI PR review: import a PR → run agent review → grounded findings.
Starter template; milestones M1–M8 add features back (see README roadmap).

## Stack (4 independent packages, NO workspace, each has its own lockfile)
- `client/` (@devdigest/web): Next.js 15, React 19, TanStack Query, Tailwind 4 — pnpm, :3000
- `server/` (@devdigest/api): Fastify 5, Drizzle 0.45, Postgres 16 + pgvector, zod 3 — pnpm, :3001
- `reviewer-core/`: pure TS review engine (diff → prompt → LLM → grounding) — npm
- `e2e/`: agent-browser flows, no LLM — npm
- Node ≥22, pnpm ≥10, Docker (Postgres only)

## Commands
- Everything: `./scripts/dev.sh` (flags: `--no-seed --no-client --db-only`)
- Per package: `pnpm dev | test | typecheck` (reviewer-core/e2e: `npm test`)
- DB: `cd server && pnpm db:migrate | db:seed | db:generate`
- Server unit: `pnpm exec vitest run --exclude '**/*.it.test.ts'`
- Server integration (needs Docker): `pnpm exec vitest run .it.test`

## Map
- `server/src/modules/<name>/{routes,service,repository}.ts` — one plugin per feature
- `server/src/platform/` — DI container, config, errors, SSE; `server/src/adapters/` = ports (llm, github, git…)
- `server/src/modules/repo-intel` — codebase indexer, consume via its facade only
- `reviewer-core/src` — prompt.ts, grounding.ts, llm/, review/run.ts
- `@devdigest/shared` (zod contracts) = `server/src/vendor/shared` + `client/src/vendor/shared`

## Non-obvious conventions
- Zod contracts are route schemas AND client types; invalid input → 422 before the handler.
- DB-backed tests MUST be named `*.it.test.ts`; everything else is hermetic.
- LLM/GitHub/git are mocked via `server/src/adapters/mocks.ts`. No keys in tests.
- Secrets only via SecretsProvider (`~/.devdigest/secrets.json`), never config/DB/git.
- Agent prompts: edit `docs/agent-prompts/*.md` AND push via `PUT /agents/:id` (DB is runtime truth).

## Gotchas
- `vendor/shared` is duplicated in server and client and HAS drifted: diff both before editing a contract.
- Migrations do NOT run on boot — run `pnpm db:migrate`.
- DB schema has tables for future milestones; empty ≠ dead.
- `server/src/platform/{grounding,prompt,structured}.ts` are re-export shims; edit reviewer-core.
- Use ROOT `docker-compose.yml` (loopback-only); `server/docker-compose.yml` exposes 5432 publicly.
- Untracked `pnpm-workspace.yaml` files are local pnpm artifacts; never commit them.
- Unindexed repo → silent diff-only review (not an error).

## Do not touch
- `server/src/db/migrations/**` (generated by drizzle-kit; use `db:generate`)
- Grounding gate and `INJECTION_GUARD` semantics (reviewer-core) without a spec
- `.claude/skills/**`, `skills-lock.json` (vendored)
