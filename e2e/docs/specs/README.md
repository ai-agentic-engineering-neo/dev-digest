# e2e/docs/specs

Feature specifications generated by the `sdd-1-generate-spec` skill.

Naming convention: `[NN]-spec-[feature-name]/[NN]-spec-[feature-name].md` (zero-padded sequence, lowercase-hyphen name).

Not to be confused with [`../../specs/`](../../specs/) at the module root, which holds browser flow definitions (`*.flow.json`) for the e2e test runner — an unrelated, pre-existing use of the name "specs."
