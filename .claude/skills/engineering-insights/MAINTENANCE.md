# INSIGHTS.md maintenance

A cleanup request covers only what the user named. Run these steps only when the user explicitly asks for a cleanup, never while recording an insight. They are the only steps that may change or remove an existing line.

- Merge duplicates; remove entries once the quirk is fixed or the entry proves wrong.
- Resolve every `REVIEW NEEDED` contradiction and any other; mark one you cannot resolve `[REVIEW NEEDED]`.
- Move answered Open Questions into the matching section.
- Past ~200 entries, split by domain (e.g. `INSIGHTS-db.md`), keeping the seven sections in each file.
- Review monthly, when the user asks; keep the files in git.
