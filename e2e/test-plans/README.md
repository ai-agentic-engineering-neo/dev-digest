# Test plans — e2e

Human-readable plans for browser coverage. The executable flows live in
[../specs/](../specs/) as `NN-name.flow.json`; this folder explains **what** a flow
should prove and **why**, before it is written.

Naming: match the flow it describes — `NN-name.md` ↔ `../specs/NN-name.flow.json`.
Feature-level specs belong in the owning package's `specs/` or in
[../../specs/](../../specs/README.md).

## Template

```markdown
# NN — <flow name>

Status: planned | implemented
Flow: ../specs/NN-name.flow.json

## What it proves
## Seeded data it relies on
## Steps (user-level)
## Out of scope
```
